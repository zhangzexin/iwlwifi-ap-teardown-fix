# Security and responsible reporting / 安全与问题反馈

## Feedback channel

For non-sensitive security concerns, suspected misuse, compatibility problems, or questions about this project's scope, please [open an issue](https://github.com/zhangzexin/iwlwifi-ap-teardown-fix/issues/new).

Submit a sanitized summary first. If the report requires confidential material or details that could enable an attack, do not publish those details in an issue. Open a minimal, non-sensitive request for a private contact channel and wait for one to be agreed. This policy does not claim that GitHub private vulnerability reporting is enabled.

## 提交信息

建议提供仓库提交号、内核/驱动/固件版本、设备型号、复现步骤、预期行为和实际结果。日志只附与问题有关且经过脱敏的部分。

不要公开Wi-Fi密码、密钥、Token、完整设备配置、业务数据、设备序列号、个人信息或未脱敏的网络标识。不要上传未经授权分发的固件、内存转储或其他第三方材料。请勿为了提交报告在生产网络中反复触发崩溃或干扰他人网络。

涉及许可、无线电合规或滥用的疑问，也可以通过上述渠道先提交不含敏感信息的描述和公开依据。此渠道用于项目沟通，不替代主管部门的认定或正式法律程序。

## Support scope

This is an independent source-patch project with validation limited to the environment documented in the README and test notes. There is no general supported-version matrix, security certification, guaranteed response time, or paid support commitment. Consult the README for known limitations before testing.

The project license remains unchanged. Reporting guidance and research status add no extra restrictions to the rights granted by GPLv2.
